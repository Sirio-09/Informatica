# Informatica - Classi Terze - Esercizio 7.1 - Console Applications

Una matrice è una struttura dati che consente di memorizzare una collezione di elementi dello stesso tipo, organizzati in righe e colonne. Nella lezione di
oggi vedremo come usarle e faremo alcuni esempi sulle matrici ***quadrate*** in C&sharp;.

### Obiettivi

Implementare tutte le funzioni definite nel file `Program.cs`. è possibile usare la funzione `Main()` per testare il codice "a mano", ma le funzioni verranno direttamente richiamate dai test automatici.
